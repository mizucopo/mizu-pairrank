# README の画面画像を更新する

README の画像は、`docs/screenshots/sample.ts` の架空の「お気に入りのおやつ」を、現行の `src/lib/view.ts` と `src/styles.css` で表示した画面です。UIを描き直したモック画像ではありません。評価値・比較回数は撮影専用の固定サンプルで、実際の比較結果を示すものではありません。

データベースや画像検索、資格情報ストアへはアクセスしません。画像は `docs/screenshots/assets/` に同梱した再利用可能なデザート写真を読み込みます。撮影時に外部サイトへの画像リクエストは行いません。利用者の個人情報・認証情報・私物の写真は含めません。写真の出典とライセンスは [画像クレジット](screenshots/assets/CREDITS.md) に記録しています。

## 撮影手順

1. [開発環境](development.md)を準備し、リポジトリ直下で `npm ci` を実行します。
2. `npm run dev -- --host 127.0.0.1` で撮影用ページをローカル表示します。使用中のポートと衝突する場合は Vite の `--port` を指定し、URLも合わせます。
3. ブラウザで以下のページを開き、日本語フォントの読み込みが完了してからページ領域を撮影します。ブラウザのツールバー・他のタブ・デスクトップ・拡張機能の表示は画像に含めません。必要に応じて空白の余白だけを切り取り、アプリの見出し・ボタン・サイドバーは残します。

| 画面       | URL                                                    | 保存先                       |
| ---------- | ------------------------------------------------------ | ---------------------------- |
| 項目       | `http://127.0.0.1:1420/docs/screenshots/?view=items`   | `docs/images/items.png`      |
| 比較       | `http://127.0.0.1:1420/docs/screenshots/?view=compare` | `docs/images/comparison.png` |
| ランキング | `http://127.0.0.1:1420/docs/screenshots/?view=ranking` | `docs/images/ranking.png`    |
| Tier 表    | `http://127.0.0.1:1420/docs/screenshots/?view=tier`    | `docs/images/tier.png`       |

4. 4枚すべてを開いて、日本語が読めること、見出しやボタンが欠けていないこと、サンプル以外のデータがないことを確認します。READMEの画像リンクも確認します。

このページは画面描画だけを行う撮影用フィクスチャで、ボタンの操作や保存は行いません。通常のアプリをブラウザだけで利用可能にするものではなく、Tauriのネイティブウィンドウ・ファイル選択・保存処理のテストにも代用できません。アプリ本体のビルドエントリーには含まれません。
