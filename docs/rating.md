# 評価と比較

## 評価モデル

[rating.rs](../src-tauri/src/rating.rs) は、TrueSkillの正規分布モデルを5段階の相対的な好みに拡張する。1回答を1観測として対象2項目の周辺分布を条件付き正規分布のモーメントで更新する。「大好き」は好みの差の大きさを表し、勝利を複数回繰り返す扱いにはしない。

モデルバージョンは `1`。初期値は μ=25、σ=25/3、性能ノイズ β=25/6、τ=0 で、時間経過によるσの増加は行わない。性能差 D=A−B の境界を ε=Φ⁻¹(0.55)×√2×β、s=2β とする（Φは標準正規分布の累積分布関数）。

| 回答      | 観測区間 |
| --------- | -------- |
| Bが大好き | D<−s     |
| Bが好き   | −s≤D<−ε  |
| 同じ      | −ε≤D<ε   |
| Aが好き   | ε≤D<s    |
| Aが大好き | D≥s      |

初期値・境界・終了条件はモデルバージョンとともにリストへ保存する。[database.rs](../src-tauri/src/database.rs) は起動時に全リストを確認し、非対応のモデルバージョン・パラメーターがあればDB初期化を拒否する。起動後も対象リストの操作を拒否し、保存済みの評価を読み替えない。

## ペア選択と順位判定

全候補ペアを走査し、5回答の予測確率で重み付けした周辺Gaussian KLの合計が最大のペアを選ぶ。計算には等価な期待エントロピー減少の式を使い、同点なら比較回数の少ない順、ID順で決める。計算はRustのワーカースレッドで行い、A/Bの表示位置はランダム化する。ASAP全体を実装したものではない。

表示順位はμ降順、同値なら登録順。N項目に対し W=max(20,N) 回答の前後を含む W+1 順位フレームを使い、全項目の σ≤2.5 かつ各項目の順位幅≤1 で「順位ほぼ確定」とする。項目の追加・削除・比較再開では判定窓をリセットし、評価は保持する。この条件は順位が正しい確率を表さない。

## スキップと取り消し

スキップは表示位置に依存しないID組をメモリ内で保留し、候補から除外する。スキップ時の項目数をNとし、同じリストへの max(1,N−1) 回答が保存されると候補へ戻す。別ウィンドウの回答も数えるが、スキップ自体は評価・比較回数・比較履歴・順位フレームを進めない。全候補が保留の場合は「順位ほぼ確定」と扱わず停止し、明示的な再開で解除する。

保留はリスト切替・アプリ再起動、比較リセットや項目構成変更による順位履歴の再開でも解除する。順位フレームの先頭・末尾IDを同じ読取りスナップショットで返し、前回の末尾より新しい先頭になった場合に履歴の再開を検出する。通常の履歴窓の移動で前回の末尾が失われるまでには、保留期間以上の回答が保存される。

直前の回答だけを1回取り消せる。保存成功後、対象2項目の回答前の評価・比較回数、追加した比較と順位フレームのID、判定窓から削除したフレームをDB接続のメモリ内に保持する。保存後のrevisionが現在と一致する場合だけ、同じ書き込みトランザクションで復元し、revisionを増やして保持情報を消費する。項目・画像・タグは復元対象に含めない。新しい回答で保持情報を置き換え、多段の取り消し・やり直しや再起動をまたぐ取り消しは行わない。利用者向けの操作条件は[README](../README.md#使い方)を参照する。
