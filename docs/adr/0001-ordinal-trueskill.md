# TrueSkillを5段階の好みへ拡張する

回答の強弱は相手との好みの差を表すため、TrueSkillの正規分布モデルを維持し、性能差の観測を5つの区間へ拡張する。標準TrueSkillの勝敗を繰り返す方式は1回答を複数の独立観測として扱い、不確実性を過度に減らすので採用しない。初期値・境界・終了条件はモデルバージョンとともにリストへ保存し、非対応のモデルを黙って読み替えない。

初期値はμ=25、σ=25/3、β=25/6、τ=0。性能差D=A−Bを、ε=Φ⁻¹(0.55)×√2×βとs=2βにより、Bが大好き: D<−s、Bが好き: −s≤D<−ε、同じ: −ε≤D<ε、Aが好き: ε≤D<s、Aが大好き: D≥sに分ける。条件付き正規分布のモーメントから対象2項目の周辺分布を1回更新する。これは静的な好みを整理するためのモデルで、時間経過によるσの増加は行わない。

ペア選択は、5回答の予測確率で重み付けした更新前後の周辺Gaussian KLの合計を最大化する。同じモーメント更新では期待エントロピー減少と等価なので、その式で計算する。全ペアを走査し、同点は比較回数、ID順で決める。計算はRustのワーカースレッドで行い、A/Bの表示位置はランダム化する。

表示順位はμ降順、同値は登録順。N項目に対しW=max(20,N)回答と直前のW+1順位フレームを使用し、全項目σ≤2.5かつ各項目の順位幅≤1で「順位ほぼ確定」とする。追加・削除・再開で判定窓をリセットする。これらの数値は製品の初期設定で、順位が正しい確率を表すものではない。

参考: [TrueSkill](https://www.microsoft.com/en-us/research/project/trueskill-ranking-system/)、[ASAPの期待情報量](https://www.cl.cam.ac.uk/~rkm38/pdfs/mikhailiuk2020asap.pdf)。本アプリはASAP全体を実装したものではない。
